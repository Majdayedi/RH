# RH Form Management System - CV Brief Description

## Project Summary for CV/Resume

### One-Line Description
**AI-Powered HR Form Management System** - Enterprise web application for creating, managing, and analyzing HR forms with intelligent sentiment analysis

### Brief Description (50-75 words)
Developed a comprehensive HR form management system using Laravel 12.x and Python AI models. The platform features a drag-and-drop form builder with 12+ field types, multi-tenant architecture supporting multiple companies, and AI-powered sentiment analysis (98.7% accuracy) using transformer models. Includes multi-language support (English, French, Arabic with RTL), automated report generation, and real-time analytics dashboard for data-driven HR decision making.

### Extended Description (100-150 words)
Architected and developed an enterprise-grade HR form management system using Laravel 12.x (PHP 8.2+) with integrated AI/ML capabilities. The platform enables HR departments to create custom forms through an intuitive drag-and-drop interface, collect responses, and generate intelligent insights using state-of-the-art NLP models (cardiffnlp/twitter-roberta for sentiment analysis, Facebook BART for summarization). Implemented multi-tenant architecture with secure company data isolation, supporting unlimited organizations. Built comprehensive internationalization with full support for English, French, and Arabic (including RTL layout). Features include real-time dashboards, PDF report generation, role-based access control, and statistical analytics. The system processes form submissions and delivers actionable insights through AI-powered sentiment analysis with 98.7% accuracy, helping organizations make data-driven HR decisions.
